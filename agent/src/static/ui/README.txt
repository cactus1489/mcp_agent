AI 이삭이 로컬 채팅 UI

실행 중인 FastAPI 서버에서 http://localhost:8000/ 또는 /ui를 엽니다.
인증키 입력 없이 질문을 바로 전송합니다.
브라우저는 POST /ui/chat에 질문만 보내고, 서버가 .env의 AGENT_API_KEY를
Authorization 헤더에 붙여 내부적으로 기존 POST /chat에 전달합니다.
인증키는 브라우저에 전달하거나 저장하지 않습니다. 기존 /chat의 인증 검사는 유지됩니다.
자동 인증은 localhost, 127.0.0.1, ::1의 같은 출처 로컬 UI 요청에만 허용됩니다.

답변 생성은 기존 POST /chat에서만 처리합니다. 별도 날씨·뉴스 API는 사용하지 않습니다.
최근 대화는 현재 탭에서만 유지됩니다. 후속 질문은 설정에 따라 최근 6개 메시지를
request 문자열에 포함합니다. 백엔드에 별도의 세션 API나 message_history는 추가하지 않았습니다.
브라우저에서 응답 대기를 중단해도 서버에서 이미 시작된 작업은 계속될 수 있습니다.

디자인 참고: https://rda-dev.clabi.co.kr/
캐릭터 이미지와 Pretendard 글꼴은 위 참고 사이트의 공개 정적 자산을 사용했습니다.
현재 화면은 로컬 MCP Agent 연결용이며, 참고 사이트의 날씨·뉴스·음성 기능은 포함하지 않습니다.
